## 📌 プロジェクト紹介

モバイルオンデバイス(On-device)AIを活用し、リアルタイムで過積載車両を検知するAndroidアプリケーションです。
サーバー通信なしにスマートフォン自体の性能だけで車両の過積載の有無を判別し、取り締まり現場での効率性と安全性を高めることを目標としています。

<br>

## ✨ 主な機能

- **リアルタイム検知:** カメラのプレビュー画面での即時的なオブジェクト認識 (30fps以上)  
- **過積載の分類:** 車種と過積載の有無を組み合わせた6つのクラス判別
- **オフライン動作:** インターネット接続なしにスマートフォン単体(On-device)で独立して実行

## 🛠️ 使用技術

- **AI Model:** YOLOv8 (Trained on Custom Dataset -> .tflite Quantization)
- **Mobile:** Android (Kotlin), CameraX
- **Inference:** TensorFlow Lite (GPU Delegate)
- **Environment:** Python 3.9, Android Studio
- **Dataset:** 過積載車両の道路危険データ (AI Hub公開データセット、遂行機関: (株)SDM E&C)
<br>

## 🚧 試行錯誤およびモデル選定のプロセス

### 第1段階: 画像分類アプローチと失敗
* **試み:** 初期は軽量かつ性能が検証されたEfficientNetを使用し、過積載の有無を判別する二値分類(Binary Classification)を試みました。
* **現象:** 初期サンプルデータ2万枚で学習後、4,000枚の検証データで精度95%を達成し、可能性を示しました。しかし、全体データセット33万枚に学習規模を拡大したところ、精度が70%台に急落する現象が発生しました。
* **問題:** 「データが増えれば性能が向上する」という一般的な常識とは異なり、分類モデルが大容量データの多様な変数(背景、撮影角度など)を消化できず、汎化(Generalization)に失敗しました。

### 第2段階: 車種別の細分化の試み
* **仮説1:** 「2万枚のデータセットの品質だけが特別に良かったのではないか？」
    * **検証:** 学習済みの2万枚モデルで4万枚の検証セットをテストしましたが、依然として低い性能を記録。データ量の問題ではないことを認知。
* **仮説2:** 「小型/中型/大型の形状の違いが大きく、学習を妨げているのではないか？」
    * **検証:** 車種を先に分類(小/中/大)し、それぞれ過積載を判断するパイプラインを構築しましたが、根本的な精度の低下問題を解決できず、推論速度のみが低下しました。
    
### 第3段階: 根本原因の分析
* **分析:** モデルが画像のどの部分を見て判断しているかを確認するため、Grad-CAM(Class Activation Map)の視覚化を行いました。
* **発見:**
    * 予想に反して、モデルが車両の積載箱に全く注目できていませんでした
    * **ヒートマップの赤い領域が現れない**、または背景全体にうっすらと広がる現象を確認しました。
    * すなわち、分類モデルが膨大な背景ノイズの中で「小さな車両オブジェクト」の特徴を抽出することに完全に失敗したことを視覚的に検証しました。
* **結論:** 背景を切り取り、車両領域だけを正確に見ることができる**オブジェクト検出技術**への転換を決定しました。

### 第4段階: YOLOv8の導入と最終解決
* **解決:** オブジェクトの位置を見つけると同時にクラスを分類できるYOLOv8モデルに技術スタックを全面交換しました。
* **成果:**
    1.  モデルが正確に「車両領域」のみに集中するようになり、背景ノイズの問題を解決。
    2.  小型/中型/大型および過積載の有無を一度の推論で処理し、速度と精度の両方を確保。

### 第5段階: ハイパーパラメータチューニング
* **チューニング:** YOLOv8導入の決定後、どの程度の性能が出るかまずデフォルト設定でテストしてみましたが、YOLOv8がデータセットによく適合したおかげか、チューニングなしでも高い性能を記録したため最終確定しました。

## ⚠️ 限界点および改善の方向性

### 照明環境による認識率の違い
* **現象:** 昼間や照明が明るい場所では高い精度を示しますが、**夜間や低照度環境**では認識率が低下したり、過積載と誤認識する現象が発生します。
* **原因分析:** 学習に使用されたデータセットの大部分が**昼間に撮影された画像**で構成されているため、夜間のタイヤの識別やホイールハウスの陰影処理に対する学習が不足していると思われます。
* **解決策:** ユーザーに「十分な光量が確保された場所で撮影してください」というガイドを提供。
    * **今後の課題:** 夜間のデータセットを追加収集して再学習するか、画像前処理段階で明るさ/コントラストを補正するアルゴリズムの導入が必要。
